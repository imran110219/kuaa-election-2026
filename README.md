# KUAA Election 2026 Candidate Directory

A responsive, self-contained candidate directory in `index.html`. The candidate data is embedded in the page, so it works as a local file and on GitHub Pages without a build step or network request.

## Publish with GitHub Pages

1. Push `index.html` to the repository.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, then select the branch and folder containing the page (usually `main` and `/ (root)`).
4. Save and open the published Pages URL.

The candidate cards are grouped by position. Search by name or student ID, or narrow the list by position, batch, and discipline. Batch years are inferred from the first two digits of the listed student ID (90–99 map to 1990–1999; 00–89 map to 2000–2089).
